# Perancangan UX Aplikasi Smart Home: Integrasi Teknologi untuk Kenyamanan, Keamanan, dan Efisiensi Energi

## Deskripsi Proyek
Proyek ini merancang pengalaman pengguna (UX) aplikasi Smart Home untuk mengontrol berbagai perangkat elektronik dari satu aplikasi. Riset dilakukan melalui mixed methods (kuesioner 28 responden + wawancara 3 narasumber) untuk memahami kebutuhan, hambatan, dan preferensi pengguna. Hasil riset dituangkan dalam user persona, storyboard, dan prototipe interaktif di Figma yang berfokus pada kemudahan navigasi, efisiensi kontrol, dan keamanan data.

## Tujuan
- Merancang aplikasi Smart Home yang mudah digunakan oleh semua kalangan.
- Memberikan pengalaman pengguna yang efisien, aman, dan nyaman.
- Mengintegrasikan fitur kontrol perangkat, otomatisasi, dan laporan penggunaan energi.

## Tools & Methods
- Figma (prototyping & UI design)
- Mixed Methods Research (kuesioner + wawancara)
- User Persona, Storyboard, Wireframing
- User-Centered Design

## Tahapan Proyek
1. **Latar Belakang** - Identifikasi masalah adopsi Smart Home (kerumitan, privasi, UI tidak intuitif)
2. **Riset Pengguna** - Kuesioner online (28 responden) + wawancara (3 narasumber)
3. **Analisis Pengguna** - User persona berdasarkan hasil riset
4. **Perancangan UX** - Storyboard alur interaksi pengguna
5. **Prototyping** - Prototipe interaktif di Figma
6. **UX Goals** - Effectiveness, Efficiency, Safety, Utility, Learnability, Memorability, Satisfaction
